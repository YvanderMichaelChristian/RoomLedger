## 🔧 How To Use
1. Clone Repository
```bash
git clone https://github.com/YvanderMichaelChristian/RoomLedger.git
```
2. Go To Project Directory
```bash
cd RoomLedger
```
3. Install Essential Dependencies
```bash
npm install
```
4. Compile The Code
```bash
npx tsc
```
5. Run Program
```bash
node dist/Hotel.js
```
